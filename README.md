# Hermes Paving Stones & Concretes Nigeria Ltd website

A responsive static website built with HTML, CSS and vanilla JavaScript. It uses local company logo and product photos in `assets/`.

## Open it in VS Code

Open this folder in VS Code and preview `index.html` with the Live Server extension or any local static web server. No build step or package installation is required.

## Project files

- `index.html` — page structure and content
- `styles.css` — visual styling, responsive layout and brand palette
- `script.js` — mobile navigation, product filters and WhatsApp quote form
- `assets/` — approved logo, supplied product/factory/founder photos, illustrative branded delivery trucks
